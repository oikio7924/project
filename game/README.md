# EARTHBOUND — 바다 너머의 지구

3D 협동 생존 게임의 첫 플레이어블 프로토타입입니다. 작은 무인도에서 재료를 줍고 뗏목을 제작하는 튜토리얼, 탐험 위치를 보여주는 종이 지도, 이후 전자 지도로 발전하는 지도 시스템을 담았습니다.

## 실행

1. Node.js 20.19 이상을 설치합니다.
2. 이 폴더에서 `npm install`을 실행합니다.
3. `npm run dev`를 실행한 뒤 터미널에 표시된 주소를 엽니다.

## 조작

- `W A S D`: 이동
- 마우스: 시야 회전 (게임 화면 클릭 시 포인터 잠금, `Esc`로 해제)
- `E`: 가까운 재료 줍기
- 뗏목 가까이에서 `E`: 탑승, 섬 가까이에서 `E`: 내리기
- `C`: 제작 메뉴
- `J`: 탐험 기록
- `M`: 지도 크게 보기
- `V`: 3인칭 / 1인칭 시점 전환
- 제작 메뉴에서 뗏목의 `위치 선택`을 누른 뒤 마우스로 바다 위 위치를 고르고 클릭해 확정합니다. `R`로 회전하고 `Esc`로 취소합니다.

화면 오른쪽 위 버튼으로도 시점을 선택할 수 있습니다. 섬 지형 높이에 맞춰 캐릭터가 해변에서 언덕까지 걸어 올라갑니다.

뗏목 제작에는 나뭇가지 2개, 덩굴 2개, 판자 2개가 필요합니다. 전자 지도는 프로토타입에서 지도 화면의 업그레이드 스위치로 확인할 수 있습니다.

## 다음 개발 단계
