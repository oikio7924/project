# rtu-web 배포 방법

운영 서버(`<운영 서버>`)에서 **root**로 실행합니다. 다른 웹(ht-web, bd-web)과 같은 방식입니다.

## 업데이트 (코드만 바뀔 때)

1. 이 PC에서 배포 파일을 만듭니다. `.env`와 `node_modules`는 넣지 않습니다.
   ```bash
   cd daeyang/rtu-web
   tar --exclude=node_modules --exclude=.env --exclude='*.tar.gz' -czf rtu-web-YYMMDD.tar.gz .
   ```
2. 서버 `/var/www/`에 올립니다 (WinSCP 등).
3. 서버에서 실행합니다.
   ```bash
   bash /var/www/rtu-web/deploy/update.sh /var/www/rtu-web-YYMMDD.tar.gz
   ```
   현재 폴더를 `rtu-web.bak-날짜시각`으로 복사한 뒤 새 코드를 풀고, `npm install` → 문법 검사 → `pm2 restart rtu-web` → 응답 확인까지 합니다.
   실패하면 되돌리는 명령을 화면에 알려 줍니다.
4. 브라우저에서 `http://<회사 도메인>/rtuweb/` 를 열어 확인하고, 문제가 없으면 백업 폴더를 지웁니다.

`db/schema.sql`이 바뀐 업데이트는 CHANGELOG에 적어 두고, 테이블 변경 SQL을 먼저 확인한 뒤 RTU 수집 사이 시간(매시 x0분 사이)에 실행합니다.

## 계정 관리

```bash
cd /var/www/rtu-web
node scripts/create-user.js 아이디 이름            # 새 계정 (기본 비밀번호 = .env 의 DEFAULT_PASSWORD)
node scripts/create-user.js 아이디 이름 --admin    # 관리자
node scripts/create-user.js --reset 아이디         # 비밀번호를 기본값으로 + 잠금 해제 (5회 틀리면 잠김)
node scripts/create-user.js --list                # 목록
```
기본 비밀번호(`.env`의 `DEFAULT_PASSWORD`)로 로그인한 뒤 왼쪽 아래 "비밀번호 변경"에서 바꿉니다.

## 상태 확인

```bash
pm2 status rtu-web
pm2 logs rtu-web --lines 50
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3003/rtuweb/login.html   # 200 이면 정상
```

## 첫 설치 (2026-11 한 번만 — 기록용)

1. 테이블: `mysql monitering < db/schema.sql` (`IF NOT EXISTS`라 다시 실행해도 기존 데이터는 그대로)
2. DB 계정: `mysql -e "SET @pw='비밀번호'; SOURCE db/grant.sql;"`
3. `/var/www/rtu-web`에 코드를 풀고 `.env` 작성 (`.env.example` 참고, `MARIADB_USER=rtuweb`, `SESSION_SECRET`은 무작위 값)
4. `npm install --omit=dev`
5. 원본 장부 이관: `node scripts/import-source.js preview 원격관리.xlsx 세팅관리.xlsm 확인표.xlsx` → `apply` (확인표는 `match`로 만들고 사용자가 확인)
6. `pm2 start server.js --name rtu-web && pm2 save`
7. `cp deploy/rtuweb.conf /etc/httpd/conf.d/ && apachectl configtest && systemctl reload httpd`
